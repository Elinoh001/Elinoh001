**Stack:** React • TypeScript • Vite • Tailwind CSS • Zustand • Framer Motion

🌐 [elino-os.vercel.app](https://elino-os.vercel.app) · [Source](https://github.com/Elinoh001/elino-os)

### 🎓 Quiz App
Mobile quiz app for university students: login by student ID, AI-generated quizzes filtered by subject level (university only), leaderboard, online challenges between students, notifications, quiz history, and a web-based admin panel.

**Stack:** FastAPI • PostgreSQL • Kivy • Groq (AI quiz generation) • Buildozer (Android build)

---

### 📝 FormForge
No-code mobile app builder: lets users create management mini-apps (entities, dynamic fields, forms, records) without writing code, built on a strict layered architecture (Screen → Service → Repository → Database).

**Stack:** Python • Kivy • SQLite • Repository/Factory/Observer patterns

---

**Stack:** Flutter • Riverpod • Drift (SQLite) • WorkManager

**Stack:** Flutter • Supabase (PostgreSQL) • Provider • OpenStreetMap/Overpass • Google Places API
